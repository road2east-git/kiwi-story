# Kiwi Story — 뉴질랜드 스토리 오마주 모바일 웹 게임 설계

날짜: 2026-08-15

## 배경

타이토의 1988년 아케이드 게임 The NewZealand Story에서 영감을 받은 모바일 웹 플랫포머.
GitHub Pages(정적 호스팅)에서 그대로 동작해야 하므로 빌드 도구 없이 순수 HTML/CSS/JS로 작성한다.

## 목표

- 모바일 브라우저에서 터치로 플레이 가능한 탐험형 플랫포머
- 원작의 핵심 메커닉 재현: 화살 공격, 가변 점프, **풍선 탈취/비행**, 친구 구출
- 자체 경량 물리엔진: 중력, 속도 적분, AABB 타일 충돌, 풍선 부력, 추락

## 기술 선택

- **렌더링**: HTML5 Canvas 2D, 고정 논리 해상도(가로 기준)를 화면에 맞춰 스케일
- **물리**: 자체 구현 (범용 물리엔진 대신). 타일 플랫포머는 결정적 AABB 충돌이 조작감에 유리
- **구조**: `index.html` + `style.css` + `js/` 아래 plain script 5개 (모듈 번들 불필요, file://에서도 동작)
- **에셋**: 없음. 스프라이트는 캔버스 픽셀 드로잉, 효과음은 WebAudio 합성

## 컴포넌트

| 파일 | 책임 |
|---|---|
| `js/input.js` | 키보드 + 터치 버튼 입력을 통합한 입력 상태 |
| `js/audio.js` | WebAudio 효과음 (점프, 발사, 풍선 펑, 구출 등) |
| `js/levels.js` | ASCII 타일맵 레벨 데이터 3개 + 파서 |
| `js/engine.js` | 물리(중력/적분/타일 AABB 충돌), 카메라 |
| `js/game.js` | 엔티티(플레이어, 적, 풍선, 화살), 게임 루프, 상태, 렌더링, HUD |

## 게임플레이 규칙

- 플레이어: 좌우 이동, 가변 점프(누르는 시간 비례), 화살 발사(수평)
- 적: 지상 순찰형, 풍선 비행형(사인파 부유)
- 풍선 적을 화살로 맞히면 적은 떨어지고 **빈 풍선**이 남아 천천히 떠다님
- 빈 풍선에 닿으면 탑승 → 점프 버튼으로 상승, 좌우로 이동, 중력 약화(부력)
- 가시에 풍선이 닿으면 펑 → 플레이어 낙하. 풍선에서 점프로 내릴 수도 있음
- 적/가시에 플레이어가 직접 닿으면 목숨 1 감소, 시작 지점 리스폰. 목숨 3개, 0이면 게임오버
- 레벨 끝 새장의 친구에게 닿으면 클리어 → 다음 레벨. 3레벨 클리어 시 엔딩
- 점수: 적 처치 100, 코인류 아이템 50, 구출 1000

## 조작

- 모바일: 화면 좌하단 ◀ ▶ 버튼, 우하단 점프(A)/발사(B) 버튼. 멀티터치 지원
- 데스크톱: ←→(이동), Z 또는 스페이스(점프), X(발사)

## 오류 처리 / 엣지 케이스

- 화면 회전/리사이즈 시 캔버스 재스케일
- 낙사(맵 아래로 추락) = 목숨 감소
- 오디오는 첫 사용자 입력 후 초기화(모바일 autoplay 정책)

## 테스트

- 브라우저 프리뷰(모바일 뷰포트)에서 실제 플레이 확인: 이동/점프/발사/풍선 탑승/사망/클리어
- 콘솔 에러 0 확인

## 배포

- 저장소 루트에 정적 파일 → GitHub Pages (main 브랜치 / root) 활성화만 하면 됨
