# 🥝 Kiwi Story

타이토의 1988년 아케이드 게임 **뉴질랜드 스토리(The NewZealand Story)** 에서 영감을 받은
모바일 웹 플랫포머입니다. 빌드 도구 없이 순수 HTML5 Canvas + JavaScript로 만들어져
GitHub Pages에 그대로 올리면 동작합니다.

## 게임 방법

물개에게 납치되어 새장에 갇힌 키위 친구들을 구출하세요. 총 3라운드.

- 화살로 적을 쏘아 처치 (적 100점, 코인 50점, 구출 1000점)
- **풍선을 탄 적을 쏘면 빈 풍선이 남습니다. 올라타서 하늘을 나세요!**
- 풍선은 가시에 닿으면 터지고, 너무 오래 타면 바람이 빠집니다
- 가시·적에 닿으면 목숨 1 감소 (3개 소진 시 게임 오버)

## 조작

| 동작 | 모바일 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ 버튼 | ←→ 또는 A/D |
| 점프 (길게 누르면 높이, 공중에서 한 번 더 가능) / 풍선 상승 | A 버튼 | Z, 스페이스, ↑ |
| 화살 발사 | B 버튼 | X 또는 K |
| 풍선에서 내리기 | — (자연 낙하) | ↓ |

## 로컬 실행

정적 서버로 열면 됩니다:

```bash
npx http-server -p 8123
```

브라우저에서 `http://localhost:8123` 접속. (파일을 직접 열어도(`index.html`) 동작합니다.)

## GitHub Pages 배포

1. 이 저장소를 GitHub에 푸시
2. 저장소 **Settings → Pages → Source**에서 `main` 브랜치 / `/ (root)` 선택
3. `https://<계정명>.github.io/<저장소명>/` 에서 플레이

## 구조

- `js/engine.js` — 경량 물리엔진 (중력, AABB 타일 충돌, 카메라)
- `js/levels.js` — ASCII 타일맵 레벨 3개
- `js/game.js` — 엔티티(키위·적·풍선·화살), 게임 루프, 렌더링
- `js/input.js` — 터치 + 키보드 통합 입력
- `js/audio.js` — WebAudio 합성 효과음 (외부 에셋 없음)
